## Brand & Style

This design system defines an elite, developer-centric esports competition UI for an algorithmic and tactical board gaming tournament hosted by a premier university cloud computing chapter. The atmosphere merges the high-stakes adrenaline of competitive digital sports with the disciplined, razor-sharp precision of cloud infrastructure engineering.

The visual style is **High-Contrast Dark Tech & Cyber-Esports**:
- Grounded in pitch-black and deep oceanic abyss tones that reduce visual fatigue during marathon coding and tournament brackets.
- Charged with energized AWS amber accents and luminescent electric cyan highlights, providing critical match telemetry and terminal feedback.
- Anchored by disciplined geometric frames, technical hairline borders, mono-spaced data displays, and subtle reactive glows that reward user engagement and tournament progression.

## Colors

The palette is engineered for high legibility in low-light environments, prioritizing tactical visual hierarchy and instantaneous cognitive parsing.

### Core Roles
- **Canvas Base (`#0B1120`)**: The deepest navy, acting as the bedrock foundation for the entire viewport.
- **Surface Elevation 1 (`#111827`)**: Dedicated container background for primary cards, bracket zones, and arena viewports.
- **Surface Elevation 2 (`#1E293B`)**: Layered inset panels, terminal viewports, elevated interactive tables, and table headers.
- **Primary Accent (`#FF9900`)**: AWS kinetic amber. Reserved for decisive actions, match victory states, real-time active turns, and primary CTAs.
- **Primary Interactive Hover (`#E68A00`)**: Deepened, pressurized amber for activated and pressed states.
- **Secondary Accent (`#38BDF8`)**: High-altitude electric blue. Used for algorithmic metrics, runtime telemetry, rank deltas, and network latency indicators.
- **Tertiary Accent (`#0284C7`)**: Grounded technical blue for inactive badge structures, progress rails, and code comment highlights.

### Structural & Content Hues
- **Text Dominant (`#F8FAFC`)**: Glare-free off-white for leaderboard positions, match scores, and headline typography.
- **Text Subordinate (`#94A3B8`)**: Cool slate for system metadata, developer tags, rules, and game telemetry.
- **Hairline Structural Borders (`#1E293B`)**: Passive dividing lines and container edges.
- **Interactive Structural Borders (`#334155`)**: Hoverable edges, focused inputs, and active bracket match boundaries.

## Typography

Typography establishes an unambiguous contrast between match narratives and computational metrics.

- **Primary Display & Headings (Plus Jakarta Sans)**: Delivers punchy, modern geometric shapes with a confident athletic posture. Used for game stages, tournament titles, and stage match-ups.
- **Interface & Narrative Body (Inter)**: Built for neutral, high-density legibility across competitor bios, rule engines, documentation, and chat logs.
- **Telemetry, System Badges & Rankings (JetBrains Mono)**: Conveys machine logic, server responses, ranking tiers, algorithms, and terminal UI controls. Tabular figures ensure aligned numerical scores across live-updating leaderboards.

## Layout & Spacing

The layout is built on a high-density, mathematical 12-column responsive fluid grid designed for complex bracket visualizations and real-time dashboard instrumentation.

### Layout Grid & Breakpoints
- **Desktop (>= 1280px)**: 12 columns, `margin: 3rem`, `gutter: 1.5rem`. Max container bound: 1440px centered. Optimal for split-screen terminal output and interactive game boards.
- **Tablet (768px - 1279px)**: 8 columns, `margin: 2rem`, `gutter: 1.25rem`. Matches and standings transition to collapsable tabbed matrices.
- **Mobile (< 768px)**: 4 columns, `margin: 1rem`, `gutter: 1rem`. Arena boards switch to vertical timeline stages; terminal controls dock to sticky bottom sheets.

### Spacing System
Spatial rhythm operates on a base 4px/8px modular rhythm:
- `space-xs` (4px): Micro gaps between status badges and icon indicators.
- `space-sm` (8px): Form input inner paddings, list item gaps, and terminal line buffers.
- `space-md` (16px): Standard container padding, card header-to-body offsets, and card gaps.
- `space-lg` (24px): Inter-card margins, leaderboard section breaks, and arena status pods.
- `space-xl` (40px): Major structural block offsets, tournament tier separations, and header bands.

## Elevation & Depth

Visual hierarchy uses tiered slate-navy surfaces reinforced by chromatic hairlines and targeted luminescence, rejecting heavy blurred drop-shadows in favor of crisp technical precision.

### Elevation Hierarchy
1. **Level 0 (Canvas Base - `#0B1120`)**: Flat baseline.
2. **Level 1 (Card & Module Shells - `#111827`)**: Bordered with a continuous 1px outline in `#1E293B`.
3. **Level 2 (Active Arena Containers & Terminal Panels - `#1E293B`)**: Layered directly over Level 1 to provide functional containment. Bordered with 1px `#334155`.
4. **Level 3 (Focused & Interactive Modals)**: Floated surface (`#111827`) elevated with an ambient under-glow: `box-shadow: 0 0 24px rgba(2, 132, 199, 0.15)`.

### Chromatic Glow Tokens
- **Amber Kinetic Glow**: `box-shadow: 0 0 16px rgba(255, 153, 0, 0.35)`. Applied to active turn counters, final win triggers, and primary button hover states.
- **Cyan Signal Glow**: `box-shadow: 0 0 14px rgba(56, 189, 248, 0.25)`. Applied to tournament qualification rings, terminal dot pulses, and code block headers.

## Shapes

The design system adopts a controlled, architectural **Soft (`1`)** shape language that reinforces engineering discipline:
- Base components (buttons, text inputs, interactive chips): `4px` (`0.25rem`).
- Structural enclosures (cards, game boards, terminal frames): `8px` (`0.5rem`).
- Micro status indicators and pill tags: `12px` (`0.75rem`) to maintain legibility without becoming fully circular.

This controlled curvature maintains a clean, technical profile that avoids overly bubbly consumer aesthetics while remaining smooth and modern.

## Components

### 1. Buttons & Triggers
- **Primary AWS Action Button**: Background `#FF9900`, text `#0B1120` (Bold Plus Jakarta Sans), border-radius 4px. On hover: background `#E68A00`, with an amber glow `box-shadow: 0 0 16px rgba(255, 153, 0, 0.35)`.
- **Terminal Secondary Button**: Background `transparent`, 1px solid border `#38BDF8`, text `#38BDF8`. On hover: background `rgba(56, 189, 248, 0.08)`, subtle cyan glow.
- **System Ghost Button**: Background `transparent`, border 1px solid `#1E293B`, text `#94A3B8`. On hover: border `#334155`, text `#F8FAFC`.

### 2. Terminal Window Frame
- A signature container for algorithmic competition logs, live API responses, and match telemetry.
- Header bar: `#0B1120`, containing three macOS-style terminal dots (Left: `#EF4444`, Center: `#EAB308`, Right: `#22C55E`, size 8px).
- Center text: Terminal session title in `mono-code` (`#94A3B8`).
- Body: Background `#080D1A`, text `#F8FAFC`, code lines preceded by an electric blue prompt `> ` (`#38BDF8`).

### 3. Tournament Qualification Badges
- Pill-shaped telemetry tags using `mono-badge`.
- **Qualified / Active**: Background `rgba(255, 153, 0, 0.1)`, 1px border `#FF9900`, text `#FF9900`.
- **Eliminated / Inactive**: Background `rgba(30, 41, 59, 0.5)`, 1px border `#334155`, text `#64748B`.
- **Server Sync / Live**: Background `rgba(56, 189, 248, 0.1)`, 1px border `#38BDF8`, text `#38BDF8` with a pulsing dot indicator.

### 4. Leaderboard Matrix
- Container: Background `#111827`, border 1px `#1E293B`.
- Rows: Alternating rows with `#0B1120` and `#111827`. Hover state transitions the row border-left to a 3px accent line (`#FF9900`).
- Rank Pod: `mono-metric` typeface. Ranks 1 to 3 feature amber and cyan text highlights; ranks 4+ utilize `#94A3B8`.

### 5. Input Fields
- Background `#0B1120`, 1px border `#1E293B`, text `#F8FAFC`, placeholder `#475569`.
- Height: 40px, font: `Inter` 14px.
- Focus state: Border color transitions to `#38BDF8` with `box-shadow: 0 0 0 1px #38BDF8`.

### 6. Tactical Cards
- Background `#111827`, 1px border `#1E293B`, border-radius 8px.
- Header divided by an internal 1px hairline border (`#1E293B`).
- On competitor or interactive cards: Hover triggers border color change to `#334155` and a gentle vertical offset (`-2px`).
